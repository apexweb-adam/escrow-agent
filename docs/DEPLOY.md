# Deploying Escrow Agent

Use PayPal **sandbox** credentials only. Never put live credentials in a demo.

## Cloudflare Workers (the hosted demo)

```bash
npm ci
npm run build                  # Next.js build: type checks and prerenders the UI
node scripts/build-worker.mjs  # bundles cloudflare/worker.ts + the UI into dist/worker.js
```

Upload `dist/worker.js` as an ES module Worker with:

- compatibility flag `nodejs_compat` (for `node:crypto`, `node:async_hooks`, `Buffer`)
- an `AI` binding (Workers AI)
- plain vars: `PAYPAL_ENV=sandbox`, `PAYPAL_API_BASE=https://api-m.sandbox.paypal.com`, `LLM_MODEL=@cf/meta/llama-3.3-70b-instruct-fp8-fast`, `APP_BASE_URL=https://<your worker host>`
- secrets: `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `STATE_SECRET` (32+ random chars), optional `PAYPAL_WEBHOOK_ID`

With Wrangler that is `wrangler deploy dist/worker.js --name escrow-agent --compatibility-flags nodejs_compat` plus `wrangler secret put` for each secret. Then register a sandbox webhook pointing at `https://<host>/api/webhooks/paypal` and set its id as `PAYPAL_WEBHOOK_ID`.

## Render

`render.yaml` is a blueprint for a free Node web service. In the Render dashboard choose New, Blueprint, pick this repo, then fill `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `APP_BASE_URL` (the `onrender.com` URL), and optionally `PAYPAL_WEBHOOK_ID`, `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL`. `STATE_SECRET` is generated by Render.

For an LLM on Node hosts without a paid key, deploy `llm-proxy/worker.js` as a second Worker with an `AI` binding and a `PROXY_KEY` secret, then set `LLM_BASE_URL=https://<proxy host>/v1`, `LLM_API_KEY=<PROXY_KEY>`, `LLM_MODEL=@cf/meta/llama-3.3-70b-instruct-fp8-fast`.

## Check a deployment

```bash
node scripts/e2e.mjs https://<host>
```

It uses only the public API, needs no credentials, and prints statuses and public PayPal ids.
